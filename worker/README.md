# ИИ-разбор: свой бесплатный сервер на Cloudflare

Приложение само не обращается к ИИ. Оно отправляет запрос на **ваш** маленький сервер (Cloudflare Worker),
а тот вызывает открытую модель Llama 3.3 70B в Cloudflare Workers AI.

- **Бесплатно.** 10 000 «нейронов» в день, этого хватает примерно на 50 разборов. На бесплатном тарифе
  лимит жёсткий: когда он заканчивается, запросы просто не проходят до 00:00 UTC. Списать деньги нельзя,
  карта не нужна.
- **Приватно.** Сервер ничего не записывает и не хранит. Cloudflare не обучает модели на запросах к Workers AI.
- **Ключ.** Без вашего ключа доступа (`APP_TOKEN`) сервер никому не отвечает.

Весь процесс занимает минут 10, и всё делается с телефона в браузере. Названия кнопок в панели Cloudflare
со временем могут немного меняться, но порядок действий останется тем же.

## 1. Аккаунт
Откройте **dash.cloudflare.com**, нажмите **Sign up** и зарегистрируйтесь по email. Бесплатный тариф
(Free) выбирается по умолчанию.

## 2. Создать Worker
1. В меню слева: **Workers & Pages** → **Create** → **Create Worker** (шаблон «Hello World»).
2. Имя: `vnutri` → **Deploy**.
3. Cloudflare покажет адрес вида `https://vnutri.ВАШЕ-ИМЯ.workers.dev`. Сохраните его.

## 3. Вставить код
1. Нажмите **Edit code**.
2. Откройте на телефоне
   https://raw.githubusercontent.com/ilyamalshv-arch/android-playground/main/worker/worker.js
   и скопируйте весь текст.
3. В редакторе Cloudflare выделите всё (`worker.js`), вставьте скопированное и нажмите **Deploy**.

## 4. Подключить ИИ
Вернитесь к Worker'у → **Settings** → **Bindings** → **Add** → **Workers AI**.
Variable name: `AI` (заглавными) → **Save/Deploy**.

## 5. Ключ доступа
1. В приложении: **Настройки** → **ИИ-разбор** → **Создать ключ**. Ключ скопируется в буфер обмена.
2. В Cloudflare: Worker → **Settings** → **Variables and Secrets** → **Add**.
   Type: **Secret**, Name: `APP_TOKEN`, Value: вставьте ключ → **Deploy**.

## 6. Подключить приложение
В приложении: **Настройки** → **ИИ-разбор**:
- **Адрес сервера:** `https://vnutri.ВАШЕ-ИМЯ.workers.dev`
- ключ уже подставлен после шага 5.1.

Нажмите **Проверить соединение**. Должно появиться «Соединение работает ✓».

## Как это работает
- Приложение отправляет выбранные чувства, ваш текст и 2–4 текста школ из своей библиотеки: те, что вы
  раскрыли или сохранили, а если таких нет — подборку по умолчанию.
- Модель получает строгие инструкции (см. `SYSTEM` в `worker.js`): опираться только на эти тексты, не
  выдумывать цитаты, не ставить диагнозов, не давать советов о крупных решениях. При признаках кризиса
  она не философствует, а направляет к живым людям.
- Проверка на кризис работает дважды: в приложении до отправки и на сервере до вызова модели.
  При срабатывании модель не вызывается, а приложение показывает экран поддержки.

## Сменить модель
Worker → **Settings** → **Variables and Secrets** → переменная `MODEL` (тип Text) с id другой модели
Workers AI. Например, когда появятся деньги на Claude, можно будет переписать один вызов в `worker.js`,
и приложение менять не придётся.
