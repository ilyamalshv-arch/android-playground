# Внутри

Android-приложение: вы отмечаете, что чувствуете, а оно показывает, как на эти чувства смотрят
разные философские школы, от стоиков до мыслителей XXI века. Цель не в том, чтобы «исправить»
чувство, а в том, чтобы его осмыслить и принять.

Всё пишется с телефона через Claude Code, без ПК.

## Установка

Свежий APK: https://github.com/ilyamalshv-arch/android-playground/releases/latest
Откройте ссылку на телефоне, скачайте `.apk` и установите. Новые версии ставятся поверх старых,
и дневник при этом сохраняется.

## Что внутри

- **18 чувств**: тревога, страх, грусть, горе, одиночество, злость, стыд, вина, зависть, пустота,
  растерянность, усталость, скука, ностальгия, радость, любовь, благодарность, надежда. Для каждого
  можно выбрать силу.
- **37 школ × 18 чувств = 666 текстов**. У каждого текста есть практика на минуту и иногда цитата.
  Акцент на XVII–XXI веках: постструктурализм, теория аффекта, мысль XXI века.
  Полный список школ: [docs/schools.md](docs/schools.md).
- **Дневник**: записи, сохранённые мысли и то, что откликнулось.
- **Библиотека школ**: взгляд каждой школы на каждое чувство.

## Безопасность и приватность

- Нет разрешения на интернет: всё хранится только на телефоне, резервное копирование в облако отключено.
- Свободный текст проверяется на признаки кризиса (`data/Safety.kt`). При совпадении сначала
  открывается экран поддержки с телефонами помощи и короткой практикой заземления.
- Кнопка «Мне очень плохо — нужна помощь» всегда есть на главном экране. Если несколько тяжёлых
  чувств отмечены на максимум, появляется мягкий баннер.
- Тексты написаны по правилам: не выдумывать цитаты, не романтизировать смерть и самоповреждение,
  не стыдить. Подробно в `tools/content.py` и в истории коммитов.
- Телефоны линий помощи стоит периодически перепроверять.

## Разработка

- Kotlin, Jetpack Compose, Material 3, minSdk 26.
- Контент лежит в `app/src/main/assets/content/schools/*.json`, по одному файлу на школу.
- `python3 tools/content.py --docs` проверяет контент и пересобирает `docs/schools.md`.
- Сборку делает GitHub Actions на каждый пуш, релиз выпускается только из `main`.
- Все сборки подписаны публичным ключом из `keystore/`. Для личного использования этого достаточно,
  для Google Play нужен свой ключ.
